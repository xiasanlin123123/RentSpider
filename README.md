# 安居客郑州租房爬虫（v1.0）

一个点几下就能用的小工具：选好区域，点「开始采集」，桌面上就会多一个 Excel 表格，里面是安居客郑州正在出租的房源，但是要注意，程序可能要人工配合去消除网站的人机验证，放心，他会自动跳转到人机验证的界面。

不用注册、不用登录、不用填 Cookie，双击就能跑。

## 它能干什么

- **按区域采**：先选大区（金水、二七、郑东新区……），再选这个区下面的商圈，比如「曼哈顿」。不想限定商圈，就选「全部（不限商圈）」。
- **自动翻页**：一页一页往下采，采完为止。
- **随时能停**：点「停止」或者直接关掉窗口都行，已经采到的数据不会丢。
- **自动去重**：同一个房源不会重复出现。
- **遇到验证码会叫你来帮忙**：安居客偶尔会弹人机验证，程序会自己打开浏览器，你在浏览器里点一下验证按钮，再回程序点「确定」，就接着采了。


采集表格做了点小处理，看着不累：表头是蓝底白字，隔一行浅蓝色，表头和第一列都锁住了——往右拉的时候不会看丢是哪一行。最后一列是能点的超链接。

## 怎么用

**最简单的办法**：下载 `安居客郑州租房爬虫.exe`，双击。

1. 第一个下拉框选大区，第二个下拉框会自动列出这个区的商圈
2. 挑一个商圈（也可以选「全部（不限商圈）」）
3. 「验证用浏览器」一般不用管，保持默认就行
4. 点「开始采集」
5. 跑完之后，表格自动存到**桌面**上，文件名像 `安居客_金水-曼哈顿_20261001_183738.xlsx`

> 采的时候每页会停 3~5 秒，这是故意的。采太快容易被安居客拦下来，建议别改。
